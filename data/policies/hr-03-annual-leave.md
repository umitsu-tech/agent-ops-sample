# 年次有給休暇規程

規程番号: HR-03 / 主管: 人事部 / 最終改定: 2025年4月1日

## 対象者

この規程は、正社員と契約社員に適用する。パートタイマーの年次有給休暇は、パートタイマー就業規則による。

## 付与日数

入社日に5日、入社日から6か月後に5日を付与する。以降は、入社日から1年6か月後を最初として、1年ごとに次の日数を付与する。

| 入社日からの期間 | 付与日数 |
|---|---|
| 1年6か月 | 11日 |
| 2年6か月 | 12日 |
| 3年6か月 | 14日 |
| 4年6か月 | 16日 |
| 5年6か月 | 18日 |
| 6年6か月以上 | 20日 |

## 取得の単位

年次有給休暇は、1日、半日、または1時間を単位として取得できる。時間単位で取得できるのは、1年に5日分までとする。

## 申請

取得する日の3営業日前までに、勤怠システムで申請する。連続して5日以上取得するときは、2週間前までに申請する。

急な病気などでやむを得ないときは、当日の始業時刻までに上長に連絡すれば、事後に申請してよい。

## 有効期限と繰り越し

年次有給休暇の有効期限は、付与した日から2年間とする。翌年に繰り越せるのは20日までとし、保有できる日数は40日までとする。

## 計画的付与

毎年8月の第2週のうち3日間を、年次有給休暇の計画的付与日とする。当社には夏季休暇という名前の特別休暇はなく、この3日間は各自の年次有給休暇から差し引く。
